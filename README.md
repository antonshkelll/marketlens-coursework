# MarketLens

**Учебный маркетплейс с объяснимыми рекомендациями и воспроизводимым экспериментом.**

[Открыть витрину](https://antonshkelll.github.io/marketlens-coursework/) · [Курсовая работа](research/) · [Происхождение данных](DATA_SOURCES.md) · [Развёртывание](DEPLOY.md)

Каталог, фильтры и поиск, корзина, демозаказ, выбор профиля, объяснение рекомендации, журнал сессии и лаборатория. Товар отделён от предложения продавца, история заказа — от действий пользователя, а выдача — от перехода по ней.

## Что проверено

| Проверка | Результат |
| --- | --- |
| Реляционная модель | 14 отношений, ключи, ограничения и триггеры вставки |
| Сессии | SQL `LAG` и накопительная сумма; разрыв **более** 30 минут |
| Рекомендации | Популярность и нормированная совместная встречаемость покупок |
| Утечка будущих данных | Общие временные границы и тест неизменности прошлого прогноза |
| Историческая цена | Изменение предложения не меняет позицию заказа |
| Контрольные сценарии | 20 тестов: 12 ядра и 8 HTTP |
| Реальный эксперимент | 50 000 посетителей Retailrocket, 354 863 события |

**Честный результат:** на реальном тесте две стратегии показали одинаковую точность. Пользователей с подходящими новыми покупками оказалось 31; большой размер когорты не делает эту оценку устойчивой. Подробнее — в [паспорте данных](DATA_SOURCES.md).

## Два режима

- **GitHub Pages:** статическая витрина и зафиксированные результаты. Корзина и демопокупки хранятся в браузере; общего серверного заказа нет.
- **Локальный сервер:** события, выдачи и демозаказы сохраняются в SQLite. Платежи, доставка и реальные персональные данные не используются.

```sh
python experiment.py
python -m unittest discover -s tests -v
python server.py
```

Открыть `http://127.0.0.1:8000`. Для повторения внешнего исследования: `python real_study.py` (первый запуск скачивает около 34 МБ). Приложение требует Python 3.11+ и стандартную библиотеку. Повторная генерация заменяет контрольную базу: остановите сервер и сохраните нужные демозаказы заранее.

## Где настоящие данные

360 пользователей витрины сгенерированы с фиксированным seed и используются для проверки функций. Исследовательские **50 000 посетителей** взяты из открытого [Retailrocket dataset](https://www.kaggle.com/datasets/retailrocket/ecommerce-dataset): условие активности и отбор по SHA-256 используют только историю до первой границы. Цены и карточки витрины не приписываются этим людям. Исходные события относятся к 2015 году, обращение к источнику — **13.11.2026**.

## Ограничения

Это учебный прототип. Профили магазина — демонстрационные, выбираются из списка и не являются учётными записями с аутентификацией. Синтетический эффект не подтверждает реальные предпочтения. Офлайн-метрики не доказывают рост продаж. Индекс измерен на одном запросе и одной машине. Серверная эксплуатация требует HTTPS, защиты доступа и ограничения запросов; соответствующая заготовка включена, внешний сервер ещё не подключён.
